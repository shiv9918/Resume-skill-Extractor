# Resume Skill Extractor

## Overview
This project builds a pipeline that takes sample resumes, extracts a controlled list of technical skills using an AI model, and stores the structured results. It evaluates extraction accuracy against a manually labeled ground truth set.

## Architecture
- **Language**: Python 3.10+
- **Database**: SQLite (local)
- **AI Integration**: AI calls are isolated behind a clear interface. 

## Setup Instructions
1. Clone the repository.
2. Create a virtual environment: `python -m venv venv`
3. Activate the virtual environment:
   - Windows: `venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`
